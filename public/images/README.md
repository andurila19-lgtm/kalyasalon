# KALYA SALON - Image Directory Structure

Organize high-resolution, webp-optimized salon photography here:

- `/public/images/branding/`: Logos, favicons, open-graph banners (`og-image.jpg`).
- `/public/images/hero/`: Hero backgrounds, flagship salon imagery.
- `/public/images/gallery/`: Haircut, coloring, treatment showcase images.
- `/public/images/services/`: Service category cards & feature highlights.
